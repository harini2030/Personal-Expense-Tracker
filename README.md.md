# Personal Expense Tracker

## Description

Personal Expense Tracker is a console-based Java application used to manage daily expenses.

The application allows users to add, view, calculate and delete expenses.

## Features

- Add new expenses
- View all expenses
- Calculate total expenses
- Delete expenses
- Category-based expense tracking
- Simple console interface

## Technologies Used

- Java
- OOP
- ArrayList
- Scanner
- Java Collections
